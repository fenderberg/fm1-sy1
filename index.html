VERSION 0.1 / EARLY RELEASE

Ready for a little exploration?

SY1 runs on the M-VAVE FM-1 with about seven voices. It is a lighter reimplementation of Synth1; its sound has not yet been compared closely with the original.

The installer can restore M-VAVE’s stock firmware. Read the manual before installing.

Install SY1 →Download firmware ↓v0.1 · sy1-0.1.fwsc
